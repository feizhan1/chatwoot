# Chatwoot 外部智能体集成 - 详细任务清单

## 项目概述
实现 Chatwoot 收件箱机器人集成外部 AI 智能体，支持智能客服自动回复和必要时转接人工坐席的完整解决方案。

---

## 阶段一：环境准备与基础配置

### 1. Chatwoot 环境准备
- [ ] **1.1** 确认 Chatwoot 版本支持 AgentBot 功能
- [ ] **1.2** 获取 Chatwoot 管理员权限和 API 访问权限
- [ ] **1.3** 准备测试收件箱（建议创建专门的测试环境）
- [ ] **1.4** 记录必要的系统信息
  - [ ] Chatwoot URL 地址
  - [ ] 账户 ID (Account ID)
  - [ ] 收件箱 ID (Inbox ID)
  - [ ] 管理员 API Token

### 2. 外部服务准备
- [ ] **2.1** 选择 AI 服务提供商（OpenAI、Claude、百度文心等）
- [ ] **2.2** 获取 AI 服务 API 密钥
- [ ] **2.3** 准备部署环境（云服务器或本地开发环境）
- [ ] **2.4** 准备域名和 SSL 证书（生产环境必需）
- [ ] **2.5** 安装必要的开发工具
  - [ ] Node.js/Python 运行环境
  - [ ] Redis（用于缓存和队列）
  - [ ] Docker（推荐用于部署）

## 阶段二：AgentBot 创建与配置

### 3. 创建 AgentBot 实例
- [ ] **3.1** 通过 Chatwoot 管理界面创建新的 AgentBot
  - [ ] 设置机器人名称（如"AI客服助手"）
  - [ ] 添加机器人描述
  - [ ] 上传机器人头像
  - [ ] 选择 bot_type 为 "webhook"
- [ ] **3.2** 配置 Webhook URL
  - [ ] 设置 outgoing_url 指向外部智能体服务
  - [ ] 确保 URL 可从 Chatwoot 访问
- [ ] **3.3** 记录 AgentBot 信息
  - [ ] AgentBot ID
  - [ ] Access Token
- [ ] **3.4** 测试 AgentBot 创建是否成功
  - [ ] 通过 API 查询 AgentBot 列表
  - [ ] 验证配置信息正确性

### 4. 收件箱绑定配置
- [ ] **4.1** 将 AgentBot 绑定到目标收件箱
- [ ] **4.2** 设置 AgentBotInbox 状态为 active
- [ ] **4.3** 验证绑定关系
  - [ ] 通过 API 查询收件箱的 AgentBot 配置
  - [ ] 确认状态为 active
- [ ] **4.4** 测试事件触发
  - [ ] 发送测试消息到收件箱
  - [ ] 检查 Webhook 是否被触发
