## 1. 核心交互功能

### 1.1 实时消息通信系统

**功能概述**: 基于 WebSocket 的双向实时消息传输，支持文本、媒体、文件等多种消息类型。

**核心价值**:
- 📡 **即时响应**: 消息延迟 < 300ms，提供接近实时的对话体验
- 🔄 **双向通信**: 访客与客服代理可同时发送和接收消息
- 💪 **可靠传输**: 断线重连机制，确保消息不丢失
- 📱 **跨设备同步**: 支持多设备间的会话连续性

**技术实现**:
```javascript
// WebSocket 连接管理
class RealTimeMessaging {
  constructor(websiteToken) {
    this.websiteToken = websiteToken;
    this.connection = null;
    this.messageQueue = [];
    this.reconnectAttempts = 0;
    this.maxReconnectAttempts = 5;
  }
  
  async connect() {
    // 建立 WebSocket 连接
    this.connection = new WebSocket(
      `wss://app.chatwoot.com/cable?token=${this.websiteToken}`
    );
    
    this.connection.onmessage = (event) => {
      const data = JSON.parse(event.data);
      this.handleMessage(data);
    };
    
    this.connection.onclose = () => {
      this.handleDisconnect();
    };
  }
  
  sendMessage(content, type = 'text') {
    const message = {
      action: 'speak',
      content: content,
      message_type: type,
      echo_id: this.generateEchoId(),
      timestamp: Date.now()
    };
    
    if (this.connection.readyState === WebSocket.OPEN) {
      this.connection.send(JSON.stringify(message));
    } else {
      // 离线时加入队列
      this.messageQueue.push(message);
    }
  }
  
  handleDisconnect() {
    console.warn('WebSocket disconnected, attempting to reconnect...');
    
    if (this.reconnectAttempts < this.maxReconnectAttempts) {
      setTimeout(() => {
        this.reconnectAttempts++;
        this.connect();
      }, Math.pow(2, this.reconnectAttempts) * 1000); // 指数退避
    }
  }
}
```

**使用场景**:
1. **即时客服**: 访客在浏览产品时遇到问题，点击聊天气泡立即与客服对话
2. **售前咨询**: 潜在客户询问产品详情，客服实时回答并推送相关资料
3. **技术支持**: 现有客户遇到使用问题，通过聊天快速获得技术帮助
4. **订单跟踪**: 客户查询订单状态，客服实时查看并反馈最新信息

- 😊 **客户满意度**: 即时响应提高客户满意度，CSAT 平均提升 20%

**技术实现**:
```vue
<!-- ChatMessage.vue - 多媒体消息渲染 -->
<template>
  <div class="chat-message" :class="messageClasses">
    <!-- 文本消息 -->
    <div v-if="message.content_type === 'text'" class="message-text">
      <div v-html="formattedContent" class="message-content"></div>
    </div>
    
    <!-- 图片消息 -->
    <div v-else-if="message.content_type === 'image'" class="message-image">
      <img 
        :src="message.attachment_url" 
        :alt="message.attachment_name"
        @click="openImageViewer"
        class="img-thumbnail cursor-pointer"
      />
    </div>
    
    <!-- 文件消息 -->
    <div v-else-if="message.content_type === 'file'" class="message-file">
      <div class="file-card">
        <div class="file-icon">
          <i :class="getFileIcon(message.file_type)"></i>
        </div>
        <div class="file-info">
          <h4>{{ message.attachment_name }}</h4>
          <p>{{ formatFileSize(message.file_size) }}</p>
        </div>
        <button @click="downloadFile" class="download-btn">
          <i class="icon-download"></i>
        </button>
      </div>
    </div>
    
    <!-- 音频消息 -->
    <div v-else-if="message.content_type === 'audio'" class="message-audio">
      <AudioPlayer 
        :src="message.attachment_url"
        :duration="message.audio_duration"
      />
    </div>
  </div>
</template>

<script>
export default {
  name: 'ChatMessage',
  props: ['message'],
  
  computed: {
    formattedContent() {
      return this.processTextContent(this.message.content);
    },
    
    messageClasses() {
      return {
        'user-message': this.message.sender_type === 'User',
        'agent-message': this.message.sender_type === 'Agent',
        'system-message': this.message.sender_type === 'System'
      };
    }
  },
  
  methods: {
    processTextContent(content) {
      // 处理链接
      content = content.replace(
        /(https?:\/\/[^\s]+)/g,
        '<a href="$1" target="_blank" rel="noopener">$1</a>'
      );
      
      // 处理换行
      content = content.replace(/\n/g, '<br>');
      
      // 处理 Emoji
      return this.parseEmoji(content);
    },
    
    getFileIcon(fileType) {
      const iconMap = {
        'pdf': 'icon-file-pdf',
        'doc': 'icon-file-word',
        'xls': 'icon-file-excel',
        'default': 'icon-file'
      };
      return iconMap[fileType] || iconMap.default;
    },
    
    formatFileSize(bytes) {
      if (bytes === 0) return '0 B';
      const k = 1024;
      const sizes = ['B', 'KB', 'MB', 'GB'];
      const i = Math.floor(Math.log(bytes) / Math.log(k));
      return parseFloat((bytes / Math.pow(k, i)).toFixed(2)) + ' ' + sizes[i];
    }
  }
};
</script>
```

### 1.3 输入状态指示器

**功能概述**: 实时显示对话双方的输入状态，包括"正在输入"、"已读"等状态信息。

**状态类型**:
```javascript
const TypingStates = {
  TYPING: 'typing',        // 正在输入
  STOPPED: 'stopped',      // 停止输入
  SENT: 'sent',           // 消息已发送
  DELIVERED: 'delivered',  // 消息已送达
  READ: 'read'            // 消息已读
};
```

**技术实现**:
```javascript
// 输入状态管理
class TypingIndicator {
  constructor(websocket) {
    this.ws = websocket;
    this.typingTimer = null;
    this.isTyping = false;
    this.typingUsers = new Set();
  }
  
  startTyping(userId) {
    if (!this.isTyping) {
      this.isTyping = true;
      this.ws.send(JSON.stringify({
        action: 'typing_start',
        user_id: userId
      }));
    }
    
    // 重置计时器
    clearTimeout(this.typingTimer);
    this.typingTimer = setTimeout(() => {
      this.stopTyping(userId);
    }, 3000); // 3秒后自动停止
  }
  
  stopTyping(userId) {
    if (this.isTyping) {
      this.isTyping = false;
      this.ws.send(JSON.stringify({
        action: 'typing_stop',
        user_id: userId
      }));
    }
    clearTimeout(this.typingTimer);
  }
  
  handleTypingEvent(data) {
    if (data.action === 'typing_start') {
      this.typingUsers.add(data.user);
      this.showTypingIndicator(data.user);
    } else if (data.action === 'typing_stop') {
```

```javascript
        priority: conversation.priority,
        workload: this.workload.getLoad(agent.id)
      })
    }));
    
    // 5. 选择最佳匹配
    scores.sort((a, b) => b.score - a.score);
    const selectedAgent = scores[0]?.agent;
    
    if (selectedAgent) {
      await this.assignConversation(conversation.id, selectedAgent.id);
      this.workload.incrementLoad(selectedAgent.id);
    }
    
    return selectedAgent;
  }
  
  calculateMatchScore(agent, requirements) {
    let score = 0;
    
    // 技能匹配 (权重: 40%)
    const skillMatch = this.calculateSkillMatch(agent.skills, requirements.skills);
    score += skillMatch * 0.4;
    
    // 语言能力 (权重: 20%)
    const languageMatch = agent.languages.includes(requirements.language) ? 1 : 0;
    score += languageMatch * 0.2;
    
    // 工作负载 (权重: 25%)
    const maxLoad = 10;
    const loadFactor = Math.max(0, (maxLoad - requirements.workload) / maxLoad);
    score += loadFactor * 0.25;
    
    // 在线状态 (权重: 10%)
```

```javascript
// 动态表单生成器
class IntelligentPreChatForm {
  constructor() {
    this.behaviorTracker = new VisitorBehaviorTracker();
    this.contextAnalyzer = new PageContextAnalyzer();
    this.formBuilder = new DynamicFormBuilder();
  }
  
  async generateForm(visitorContext) {
    // 1. 分析访客行为
    const behavior = await this.behaviorTracker.analyze(visitorContext);
    
    // 2. 分析页面内容
    const pageContext = await this.contextAnalyzer.analyze({
      url: window.location.href,
      title: document.title,
      content: this.extractPageContent()
    });
    
    // 3. 推断访客意图
    const intent = this.inferVisitorIntent(behavior, pageContext);
    
    // 4. 生成定制表单
    return this.formBuilder.build(intent);
  }
  
  inferVisitorIntent(behavior, pageContext) {
    const signals = {
      // 行为信号
      timeOnSite: behavior.timeOnSite,
      pagesViewed: behavior.pagesViewed,
      scrollDepth: behavior.scrollDepth,
      clickPattern: behavior.clickPattern,
      
      // 内容信号
      pageType: pageContext.type, // product, pricing, support, etc.
      category: pageContext.category,
      keywords: pageContext.keywords
    };
    
    // 意图推断规则
    if (signals.pageType === 'pricing' && signals.timeOnSite > 120) {
      return {
        intent: 'purchase_consideration',
        confidence: 0.85,
        priority: 'high'
      };
    }
    
    if (signals.pageType === 'product' && signals.scrollDepth > 0.8) {
      return {
        intent: 'product_interest',
        confidence: 0.75,
        priority: 'medium'
      };
    }
    
    if (signals.pageType === 'support' || signals.keywords.includes('help')) {
      return {
        intent: 'support_needed',
        confidence: 0.9,
        priority: 'high'
      };
    }
    
    return {
      intent: 'general_inquiry',
      confidence: 0.6,
      priority: 'medium'
    };
  }
}
```

```javascript
class SmartFieldSelector {
  constructor() {
    this.fieldLibrary = {
      // 基础字段
      basic: [
        { name: 'fullName', type: 'text', required: true },
        { name: 'email', type: 'email', required: true },
        { name: 'phone', type: 'tel', required: false }
      ],
      
      // 业务相关字段
      business: [
        { name: 'company', type: 'text', required: false },
        { name: 'jobTitle', type: 'text', required: false },
        { name: 'industry', type: 'select', required: false },
        { name: 'companySize', type: 'select', required: false }
      ],
      
      // 产品相关字段
      product: [
        { name: 'interestedProduct', type: 'select', required: false },
        { name: 'budget', type: 'select', required: false },
        { name: 'timeline', type: 'select', required: false }
      ],
      
      // 支持相关字段
      support: [
        { name: 'issueType', type: 'select', required: true },
        { name: 'urgency', type: 'select', required: true },
        { name: 'orderNumber', type: 'text', required: false }
      ]
    };
  }
  
  selectFields(intent, context) {
    const fields = [...this.fieldLibrary.basic]; // 始终包含基础字段
    
    switch (intent.intent) {
      case 'purchase_consideration':
        fields.push(...this.fieldLibrary.business);
        fields.push(...this.fieldLibrary.product);
        break;
        
      case 'product_interest':
        fields.push(...this.fieldLibrary.product.slice(0, 2));
        if (context.isBusinessSite) {
          fields.push(...this.fieldLibrary.business.slice(0, 2));
        }
        break;
        
      case 'support_needed':
        fields.push(...this.fieldLibrary.support);
        break;
        
      default:
        // 通用咨询，保持字段最少
        break;
    }
    
    // 基于页面内容进一步过滤
    return this.contextualFilter(fields, context);
  }
  
  contextualFilter(fields, context) {
    // 如果是产品页面，预填充产品信息
    if (context.pageType === 'product') {
      const productField = fields.find(f => f.name === 'interestedProduct');
      if (productField) {
        productField.defaultValue = context.productName;
        productField.disabled = true;
      }
    }
    
    // 如果检测到企业邮箱，显示商业字段
    if (context.hasBusinessEmail) {
      return fields.filter(f => !f.excludeForBusiness);
    }
    
    return fields;
  }
}
```

```vue
<script>
export default {
  name: 'IntelligentPreChatForm',
  
  data() {
    return {
      formData: {},
      formFields: [],
      formConfig: {},
      suggestions: [],
      isSubmitting: false
    };
  },
  
  async mounted() {
    await this.generateIntelligentForm();
  },
  
  computed: {
    isFormValid() {
      return this.formFields
        .filter(field => field.required)
        .every(field => this.formData[field.name]?.trim());
    },
    
    showSuggestions() {
      return this.suggestions.length > 0;
    }
  },
  
  methods: {
    async generateIntelligentForm() {
      const generator = new IntelligentPreChatForm();
      const visitorContext = await this.getVisitorContext();
      
      const formConfig = await generator.generateForm(visitorContext);
      
      this.formFields = formConfig.fields;
      this.formConfig = formConfig.config;
      this.suggestions = formConfig.suggestions || [];
      
      // 预填充已知信息
      this.prefillKnownData(visitorContext);
    },
    
    async getVisitorContext() {
      return {
        // 页面信息
        currentUrl: window.location.href,
        pageTitle: document.title,
        referrer: document.referrer,
        
        // 用户行为
        timeOnSite: Date.now() - performance.timing.navigationStart,
        scrollDepth: this.calculateScrollDepth(),
        
        // 设备信息
        userAgent: navigator.userAgent,
        language: navigator.language,
        timezone: Intl.DateTimeFormat().resolvedOptions().timeZone,
        
        // UTM 参数
        ...this.parseUTMParams()
      };
    },
    
    prefillKnownData(context) {
      // 基于 UTM 参数预填充
      if (context.utm_source) {
        this.formData.referralSource = context.utm_source;
      }
      
      // 基于页面内容预填充
      if (context.pageType === 'product') {
        this.formData.interestedProduct = context.productName;
      }
    },
    
    applySuggestion(suggestion) {
      // 应用智能建议
      Object.assign(this.formData, suggestion.data);
      
      // 移除已应用的建议
      this.suggestions = this.suggestions.filter(s => s.key !== suggestion.key);
    },
    
    async submitForm() {
      this.isSubmitting = true;
      
      try {
        // 提交表单数据
        const response = await this.$api.post('/api/v1/widget/prechat', {
          formData: this.formData,
          context: await this.getVisitorContext()
        });
        
        // 开始对话
        this.$emit('form-submitted', {
          formData: this.formData,
          conversationToken: response.data.token
        });
        
      } catch (error) {
        console.error('Form submission failed:', error);
        this.$toast.error('提交失败，请重试');
      } finally {
        this.isSubmitting = false;
      }
    }
  }
};
```

```javascript
function isInBusinessHours() {
  const now = new Date();

  if (!config.enabled) return true;

}
```

#### WebSocket 连接管理

```javascript
class ActionCableConnector {
  constructor(app, pubsubToken) {
    this.app = app;
    this.pubsubToken = pubsubToken;
    this.cable = null;
    this.subscription = null;
  }
  
  connect() {
    // 建立 WebSocket 连接
    this.cable = ActionCable.createConsumer(this.getWebSocketURL());
    
    // 订阅频道
    this.subscription = this.cable.subscriptions.create(
      { 
        channel: 'RoomChannel',
        pubsub_token: this.pubsubToken 
      },
      {
        received: this.onMessageReceived.bind(this),
        connected: this.onConnected.bind(this),
        disconnected: this.onDisconnected.bind(this)
      }
    );
  }
  
  onMessageReceived(data) {
    // 处理收到的消息
    this.app.$store.dispatch('conversation/addMessage', data);
    
    // 触发通知
    if (data.event === 'message.created') {
      this.showNotification(data.message);
    }
  }
  
  sendMessage(message) {
    this.subscription.send({
      action: 'speak',
      message: message
    });
  }
}
```

#### 断线重连机制
```javascript
class ConnectionManager {
  constructor() {
    this.reconnectAttempts = 0;
    this.maxReconnectAttempts = 5;
    this.reconnectInterval = 1000; // 起始间隔1秒
  }
  
  onDisconnected() {
    console.log('WebSocket 连接断开，尝试重连...');
    this.attemptReconnect();
  }
  
  attemptReconnect() {
    if (this.reconnectAttempts >= this.maxReconnectAttempts) {
      console.error('达到最大重连次数，停止重连');
      this.showConnectionError();
      return;
    }
    
    setTimeout(() => {
      this.reconnectAttempts++;
      this.connect();
      
      // 指数退避策略
      this.reconnectInterval *= 2;
    }, this.reconnectInterval);
  }
  
  onConnected() {
    console.log('WebSocket 连接已建立');
    this.reconnectAttempts = 0;
    this.reconnectInterval = 1000;
    this.hideConnectionError();
  }
}
```

```javascript
// Campaign 展示条件判断
class CampaignManager {
  shouldShowCampaign(campaign) {
    // 检查时间条件
    if (!this.isInTimeRange(campaign.scheduled_at)) {
      return false;
    }
    
    // 检查页面条件
    if (!this.matchesPageRules(campaign.trigger_rules)) {
      return false;
    }
    
    // 检查访客条件
    if (!this.matchesVisitorRules(campaign.audience)) {
      return false;
    }
    
    // 检查频率限制
    if (this.isRecentlyDismissed(campaign.id)) {
      return false;
    }
    
    return true;
  }
  
  matchesPageRules(rules) {
    const currentURL = window.location.href;
    
    return rules.some(rule => {
      switch (rule.condition) {
        case 'contains':
          return currentURL.includes(rule.value);
        case 'equals':
          return currentURL === rule.value;
        case 'starts_with':
          return currentURL.startsWith(rule.value);
        case 'regex':
          return new RegExp(rule.value).test(currentURL);
        default:
          return false;
      }
    });
  }
}
```

```javascript
    }
  }
```

```javascript
    // 检查是否有用户交互记录
    return document.hasStoredUserActivation || 
           window.hasUserGestureActivation;
  }
  
  enableAudio() {

  }
  
  disableAudio() {
    this.audioEnabled = false;
```

```typescript
// chatwoot.service.ts
import { Injectable } from '@angular/core';
import { BehaviorSubject } from 'rxjs';

interface ChatwootConfig {
  websiteToken: string;
  baseUrl?: string;
  user?: any;
  customAttributes?: any;
}

@Injectable({
  providedIn: 'root'
})
export class ChatwootService {
  private loadedSubject = new BehaviorSubject<boolean>(false);
  public loaded$ = this.loadedSubject.asObservable();
  
  private scriptLoaded = false;
  
  async load(config: ChatwootConfig): Promise<void> {
    if (this.scriptLoaded) {
      this.initialize(config);
      return;
    }
    
    try {
      await this.loadScript(config.baseUrl || 'https://app.chatwoot.com');
      this.scriptLoaded = true;
      this.initialize(config);
    } catch (error) {
      console.error('Chatwoot 加载失败:', error);
      throw error;
    }
  }
  
  private loadScript(baseUrl: string): Promise<void> {
    return new Promise((resolve, reject) => {
      const script = document.createElement('script');
      script.src = `${baseUrl}/packs/js/sdk.js`;
      script.async = true;
      script.onload = () => resolve();
      script.onerror = () => reject(new Error('Script load failed'));
      document.head.appendChild(script);
    });
  }
  
  private initialize(config: ChatwootConfig): void {
    if (!(window as any).chatwootSDK) {
      throw new Error('Chatwoot SDK not loaded');
    }
    
    (window as any).chatwootSDK.run({
      ...config,
      onLoaded: () => {
        this.loadedSubject.next(true);
      }
    });
  }
  
  toggle(show?: boolean): void {
    if ((window as any).chatwootSDK) {
      (window as any).chatwootSDK.toggle(show);
    }
  }
  
  setUser(user: any): void {
    if ((window as any).chatwootSDK) {
      (window as any).chatwootSDK.setUser(user);
    }
  }
}
```

```javascript
// SPA 路由变化时更新 Widget 上下文
class SPAIntegration {
  constructor(config) {
    this.config = config;
    this.currentPath = window.location.pathname;
    this.initializeWidget();
    this.setupRouteListener();
  }
  
  initializeWidget() {
    window.chatwootSDK.run({
      ...this.config,
      onLoaded: () => {
        this.updatePageContext();
      }
    });
  }
  
  setupRouteListener() {
    // 监听 History API 变化
    const originalPushState = history.pushState;
    const originalReplaceState = history.replaceState;
    
    history.pushState = (...args) => {
      originalPushState.apply(history, args);
      this.handleRouteChange();
    };
    
    history.replaceState = (...args) => {
      originalReplaceState.apply(history, args);
      this.handleRouteChange();
    };
    
    // 监听浏览器前进后退
    window.addEventListener('popstate', () => {
      this.handleRouteChange();
    });
    
    // 监听 hash 变化 (用于 hash 路由)
    window.addEventListener('hashchange', () => {
      this.handleRouteChange();
    });
  }
  
  handleRouteChange() {
    const newPath = window.location.pathname;
    if (newPath !== this.currentPath) {
      this.currentPath = newPath;
      this.updatePageContext();
    }
  }
  
  updatePageContext() {
    // 更新页面上下文信息
    const pageInfo = {
      url: window.location.href,
      title: document.title,
      path: window.location.pathname,
      referrer: document.referrer
    };
    
    // 发送页面浏览事件
    if (window.chatwootSDK) {
      window.chatwootSDK.setCustomAttributes({
        current_page: pageInfo.path,
        page_title: pageInfo.title
      });
    }
  }
}
```

```javascript
  constructor(config) {

      this.load();
      interactionEvents.forEach(event => {
        document.removeEventListener(event, loadOnInteraction);
      });
    };
    
    interactionEvents.forEach(event => {
      document.addEventListener(event, loadOnInteraction, { passive: true });
    });

    if (document.readyState === 'complete') {
      setTimeout(() => this.load(), 3000);
    } else {

        setTimeout(() => this.load(), 3000);
      });
    }
    
    // Intersection Observer - 当用户滚动到页面底部时加载
    if ('IntersectionObserver' in window) {
      const observer = new IntersectionObserver((entries) => {
        entries.forEach(entry => {
          if (entry.isIntersecting) {
            this.load();
            observer.disconnect();
          }
        });
      });
      
      // 观察页脚元素
      const footer = document.querySelector('footer');
      if (footer) {
        observer.observe(footer);
      }
    }
  }
```

```javascript
          reason: event.reason.message,
          stack: event.reason.stack
        });
      }
    });
  }
  
  setupPerformanceMonitoring() {
    // 监控 Widget 加载性能
    const startTime = performance.now();
    
    window.addEventListener('chatwoot:loaded', () => {
      this.performance.loadTime = performance.now() - startTime;
      this.reportPerformance();
    });
  }

    const error = {
      type,
      details,
      timestamp: new Date().toISOString(),
      userAgent: navigator.userAgent,
      url: window.location.href
    };
    
    this.errors.push(error);
    
    // 发送到监控系统
    this.reportError(error);
  }

    // 发送到您的错误监控系统

      window.gtag('event', 'exception', {
        description: `Chatwoot ${error.type}: ${JSON.stringify(error.details)}`,

    }
    
    // 或发送到其他监控服务
    // Sentry, LogRocket, DataDog 等
  }

    if (window.gtag && this.performance.loadTime) {
      window.gtag('event', 'timing_complete', {
        name: 'chatwoot_load_time',

  }
```

```javascript
// Cloudflare Workers 边缘缓存
export default {
  async fetch(request, env, ctx) {
    const url = new URL(request.url);
    
    // Widget 静态资源缓存策略
    if (url.pathname.includes('/widget/') || url.pathname.includes('/packs/')) {
      const cache = caches.default;
      const cacheKey = new Request(url.toString(), request);
      
      // 检查缓存
      let response = await cache.match(cacheKey);
      
      if (!response) {
        // 从源服务器获取
        response = await fetch(request);
        
        // 设置缓存头
        const newResponse = new Response(response.body, {
          status: response.status,
          statusText: response.statusText,
          headers: {
            ...response.headers,
            'Cache-Control': 'public, max-age=86400', // 24小时
            'CDN-Cache-Control': 'public, max-age=31536000', // 1年
          }
        });
        
        // 存储到缓存
        ctx.waitUntil(cache.put(cacheKey, newResponse.clone()));
        return newResponse;
      }
      
      return response;
    }
    
    // 其他请求直接转发
    return fetch(request);
  }
};
```

```javascript
// 诊断脚本
class WidgetDiagnostics {
  constructor() {
    this.diagnostics = [];
    this.runDiagnostics();

  runDiagnostics() {
    this.checkScriptLoading();
    this.checkNetworkConnectivity();
    this.checkBrowserCompatibility();
    this.checkCSPSettings();
    this.checkLocalStorage();
    this.generateReport();
  }
  
  checkScriptLoading() {
    const scripts = document.getElementsByTagName('script');
    const chatwootScript = Array.from(scripts).find(script => 
      script.src.includes('chatwoot') || script.src.includes('sdk.js')
    );
    
    if (!chatwootScript) {
      this.diagnostics.push({
        issue: 'Chatwoot 脚本未找到',
        solution: '请检查脚本标签是否正确添加到页面中',
        severity: 'high'
      });
    }
    
    if (chatwootScript && chatwootScript.onerror) {
      this.diagnostics.push({
        issue: 'Chatwoot 脚本加载失败',
        solution: '请检查网络连接和脚本 URL 是否正确',
        severity: 'high'
      });
    }
  }
  
  checkNetworkConnectivity() {
    fetch('/api/health', { method: 'HEAD' })
      .then(response => {
        if (!response.ok) {
          this.diagnostics.push({
            issue: `服务器响应错误: ${response.status}`,
            solution: '请联系系统管理员检查服务器状态',
            severity: 'high'
          });
        }
      })
      .catch(error => {
        this.diagnostics.push({
          issue: '网络连接失败',
          solution: '请检查网络连接或防火墙设置',
          severity: 'high'
        });
      });
  }
  
  checkBrowserCompatibility() {
    const requiredFeatures = {
      'WebSocket': !!window.WebSocket,
      'localStorage': !!window.localStorage,
      'fetch': !!window.fetch,
      'Promise': !!window.Promise,
      'postMessage': !!window.postMessage
    };
    
    Object.entries(requiredFeatures).forEach(([feature, supported]) => {
      if (!supported) {
        this.diagnostics.push({
          issue: `浏览器不支持 ${feature}`,
          solution: '请使用现代浏览器或升级浏览器版本',
          severity: 'medium'
        });
      }
    });
  }
  
  checkCSPSettings() {
    // 检查内容安全策略是否阻止了脚本执行
    const violations = this.getCSPViolations();
    if (violations.length > 0) {
      this.diagnostics.push({
        issue: 'CSP 策略阻止了 Widget 加载',
        solution: '请调整 Content-Security-Policy 头部设置',
        details: violations,
        severity: 'medium'
      });
    }
  }
  
  generateReport() {
    const report = {
      timestamp: new Date().toISOString(),
      userAgent: navigator.userAgent,
      url: window.location.href,
      diagnostics: this.diagnostics
    };
    
    console.group('🔧 Chatwoot Widget 诊断报告');
    console.table(this.diagnostics);
    console.log('详细报告:', report);
    console.groupEnd();
    
    // 可选：发送诊断数据到服务器
    this.sendDiagnostics(report);
  }
}
```

```javascript
// 性能监控和分析
class PerformanceAnalyzer {
  constructor() {
    this.metrics = {};
    this.thresholds = {
      scriptLoad: 2000,    // 脚本加载时间阈值
      firstPaint: 1000,    // 首次绘制时间阈值
      interactive: 3000,   // 可交互时间阈值
      memoryUsage: 50 * 1024 * 1024 // 内存使用阈值 50MB
    };
    this.startMonitoring();
  }
  
  startMonitoring() {
    // 监控脚本加载性能
    this.monitorScriptLoading();
    
    // 监控渲染性能
    this.monitorRenderingPerformance();
    
    // 监控内存使用
    this.monitorMemoryUsage();
    
    // 监控网络请求
    this.monitorNetworkRequests();
  }
  
  monitorScriptLoading() {
    const observer = new PerformanceObserver((list) => {
      for (const entry of list.getEntries()) {
        if (entry.name.includes('chatwoot') || entry.name.includes('sdk.js')) {
          this.metrics.scriptLoadTime = entry.responseEnd - entry.requestStart;
          
          if (this.metrics.scriptLoadTime > this.thresholds.scriptLoad) {
            console.warn(`⚠️ Widget 脚本加载较慢: ${this.metrics.scriptLoadTime}ms`);
            this.suggestOptimizations('script-loading');
          }
        }
      }
    });
    
    observer.observe({ entryTypes: ['resource'] });
  }
  
  monitorMemoryUsage() {
    if (performance.memory) {
      setInterval(() => {
        const memoryUsage = performance.memory.usedJSHeapSize;
        this.metrics.memoryUsage = memoryUsage;
        
        if (memoryUsage > this.thresholds.memoryUsage) {
          console.warn(`⚠️ Widget 内存使用过高: ${(memoryUsage / 1024 / 1024).toFixed(2)}MB`);
          this.suggestOptimizations('memory-usage');
        }
      }, 30000); // 每30秒检查一次
    }
  }
  
  suggestOptimizations(issue) {
    const suggestions = {
      'script-loading': [
        '考虑使用 CDN 加速脚本加载',
        '启用 gzip 压缩',
        '使用 preload 提示预加载脚本'
      ],
      'memory-usage': [
```

```ruby
# app/controllers/concerns/widget_error_handler.rb
module WidgetErrorHandler
  extend ActiveSupport::Concern
  
  included do
    rescue_from StandardError, with: :handle_widget_error
    rescue_from ActiveRecord::RecordNotFound, with: :handle_not_found
    rescue_from ActionController::ParameterMissing, with: :handle_bad_request
  end
  
  private
  
  def handle_widget_error(exception)
    error_id = SecureRandom.uuid
    
    Rails.logger.error({
      error_id: error_id,
      exception: exception.class.name,
      message: exception.message,
      backtrace: exception.backtrace[0..5],
      request: {
        method: request.method,
        path: request.path,
        params: request.parameters,
        user_agent: request.user_agent
      }
    }.to_json)
    
    render json: {
      error: {
        code: 'INTERNAL_SERVER_ERROR',
        message: '服务器内部错误',
        error_id: error_id,
        timestamp: Time.current.iso8601
      }
    }, status: :internal_server_error
  end
  
  def handle_not_found(exception)
    render json: {
      error: {
        code: 'RESOURCE_NOT_FOUND',
        message: '请求的资源不存在',
        details: exception.message
      }
    }, status: :not_found
  end
  
  def handle_bad_request(exception)
    render json: {
      error: {
        code: 'VALIDATION_ERROR',
        message: '请求参数错误',
        details: exception.message
      }
    }, status: :bad_request
  end
end
```

```vue
<!-- ErrorBoundary.vue -->
<template>
  <div v-if="hasError" class="widget-error-boundary">
    <div class="error-content">
      <h3>😔 出了点问题</h3>

        </button>

          报告问题
        </button>

<script>
export default {
  name: 'ErrorBoundary',
  
  data() {
    return {
      hasError: false,
      errorDetails: null,
      showDetails: false
    };
  },
  
  errorCaptured(error, instance, info) {
    this.hasError = true;
    this.errorDetails = {
      error: error.message,
      stack: error.stack,
      info: info,
      timestamp: new Date().toISOString()
    };
    
    // 发送错误报告
    this.sendErrorReport(error, instance, info);
    
    // 阻止错误继续传播
    return false;
  },
  
  methods: {
    retry() {
      this.hasError = false;
      this.errorDetails = null;
      this.$forceUpdate();
    },
    
    reportError() {
      // 打开错误报告表单或重定向到支持页面
      window.open('https://support.chatwoot.com/report-issue', '_blank');
    },
    
    sendErrorReport(error, instance, info) {
      // 发送错误到监控系统
      if (window.Sentry) {
        window.Sentry.captureException(error, {
          contexts: {
            vue: {
              componentName: instance.$options.name,
              lifecycle: info
            }
          }
        });
      }
      
      // 发送到自定义错误收集端点
      fetch('/api/v1/widget/errors', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          error: error.message,
          stack: error.stack,
          component: instance.$options.name,
          lifecycle: info,
          userAgent: navigator.userAgent,
          url: window.location.href,
          timestamp: new Date().toISOString()
        })
      }).catch(reportError => {
        console.error('无法发送错误报告:', reportError);
      });
    }
  }
};
```
